# Contributing

Fork the repository, create a branch, and open a pull request describing the change and the checks you ran. Contributors do not need write access to this repository. Follow the local setup and checks in README.md.

Use synthetic practice data. Do not commit secrets, personal learner/player information, local databases, operational records, backups or generated build directories.

For assets, include their source, copyright holder, licence and required credit. Preserve third-party notices. Contributions to original code are under MIT; contributions to original artwork and training assets are under CC BY 4.0 unless an explicitly documented compatible third-party licence applies. Submit only work you are entitled to license.
