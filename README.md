# Survey Logbook

A self-contained survey logbook training application.

Open http://127.0.0.1:8080/#home after starting the static server, or use another local static server. No package installation, build step, hosted account or external data service is required. The illustrations are embedded in index.html. Use fictional names and practice data.

## Run locally

Serve this directory locally; Python is one option.

```sh
python -m http.server 8080 --bind 127.0.0.1
```
